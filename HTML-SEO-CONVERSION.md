# Decan Movie — HTML, CSS, and JavaScript

The public movie frontend is `index.html`. Styling and interactive features are provided by CSS and JavaScript files. Personal lists and playback progress are stored locally in the browser.

The Vercel JavaScript functions in `api/` provide TMDB data and SEO pages. Configure `TMDB_ACCESS_TOKEN` in Vercel environment variables; never put the private token in browser code.

The repository no longer contains PHP endpoints, SQL scripts, or account/admin pages. SEO metadata, `robots.txt`, and `sitemap.xml` remain part of the site.
